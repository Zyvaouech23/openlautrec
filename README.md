# Openlautrec
The OpenLautrec Project est un traitement de texte et outils de feuille de géométrie adapté pour le lycée Toulouse-Lautrec.
Ce logiciel est développé exclusivement en Python et sert à aider les élèves de l'EREA Toulouse-Lautrec. 

But du logiciel : 
  - Mise en forme complète du texte
  - Tableaux et listes
  - Symboles mathématiques et spéciaux
  - Export PDF et impression
  - Formats .docx, .odt, .html, .txt, .olc
  - Dictée vocale en français 🎤
  - Lecture vocale 🔊
  - Mode Dyslexie  

## Comment installer le logiciel OpenLautrec

La procédure correct se présente comme suit :

- Rendez-vous sur le site https://openlautrec-se4fs.onrender.com/#
- Téléchargez la dernière version d'OpenLautrec

Vous pouvez aussi retrouver le code source de ce projet sur le github OpenLautrec : https://github.com/Zyvaouech23/openlautrec
